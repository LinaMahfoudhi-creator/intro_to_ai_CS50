# Collection de Projets d'IA

## Description
Ce dépôt contient une collection de projets d'intelligence artificielle (IA) couvrant divers domaines, 
notamment les jeux, le traitement du langage naturel, la vision par ordinateur et l'apprentissage automatique. 
Chaque projet est autonome et met en œuvre des concepts spécifiques d'IA.
Ces projets sont les projets de la formation CS50 AI de Harvard.

## Projets Inclus

### 1. Crossword
- **Description** : Solveur de mots croisés utilisant des techniques d'optimisation.
- **Fichier principal** : `crossword.py`

### 2. Nim
- **Description** : Jeu de Nim avec une IA basée sur le Q-learning.
- **Fichier principal** : `nim.py`

### 3. Shopping
- **Description** : Modèle k-NN pour prédire les achats en ligne.
- **Fichier principal** : `shopping.py`

### 4. Traffic
- **Description** : Classification d'images de panneaux de signalisation avec un CNN.
- **Fichier principal** : `traffic.py`

### 5. Attention
- **Description** : Visualisation des scores d'attention dans les modèles de langage basés sur des transformateurs.
- **Fichier principal** : `mask.py`

### 6. Parser
- **Description** : Analyseur syntaxique pour des phrases en anglais basé sur une grammaire libre de contexte (CFG).
- **Fichier principal** : `parser.py`

## Instructions Générales
1. Assurez-vous d'avoir Python installé.
2. Consultez les instructions spécifiques à chaque projet dans leurs fichiers README respectifs.
3. Installez les dépendances nécessaires pour chaque projet à l'aide de `pip`.

## Dépendances Globales
- Python 3.12
- `pip` pour la gestion des dépendances
