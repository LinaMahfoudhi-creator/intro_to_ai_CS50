# PageRank

## Description
Ce projet implémente l'algorithme PageRank pour calculer l'importance relative des pages dans un corpus de liens hypertextes. Deux approches sont utilisées : l'échantillonnage stochastique et l'itération déterministe.

## Fonctionnalités
- Analyse des liens entre les pages dans un corpus.
- Calcul du PageRank par échantillonnage (méthode probabiliste).
- Calcul du PageRank par itération (méthode déterministe).

## Fichiers
- `pagerank.py` : Contient l'implémentation principale.

## Instructions
1. Assurez-vous d'avoir Python installé.
2. Exécutez le fichier `pagerank.py` avec un répertoire contenant des fichiers HTML :
   ```bash
   python pagerank.py corpus
