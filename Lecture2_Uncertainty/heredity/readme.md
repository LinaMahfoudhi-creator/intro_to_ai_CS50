# Heredity

## Description
Ce projet utilise des probabilités bayésiennes pour calculer la probabilité qu'une personne ait un certain nombre de copies d'un gène et présente un trait spécifique, en fonction des données généalogiques.

## Fonctionnalités
- Calcul des probabilités conjointes pour les gènes et les traits.
- Prise en compte des mutations génétiques et des probabilités conditionnelles.
- Normalisation des probabilités pour garantir que la somme est égale à 1.

## Fichiers
- `heredity.py` : Contient l'implémentation principale.

## Instructions
1. Assurez-vous d'avoir Python installé.
