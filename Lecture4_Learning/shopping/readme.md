# Shopping

## Description
Ce projet utilise un modèle de classification k-plus-proches-voisins (k-NN) pour prédire si un utilisateur effectuera un achat en ligne, en se basant sur des données de navigation.

## Fonctionnalités
- Chargement des données à partir d'un fichier CSV.
- Prétraitement des données pour les convertir en un format utilisable par le modèle.
- Entraînement d'un modèle k-NN pour effectuer des prédictions.
- Évaluation des performances du modèle (sensibilité et spécificité).

## Fichiers
- `shopping.py` : Contient l'implémentation principale.

## Instructions
1. Assurez-vous d'avoir Python installé.
2. Fournissez un fichier CSV contenant les données.
3. Exécutez le fichier `shopping.py` :
   ```bash
   python shopping.py data.csv
