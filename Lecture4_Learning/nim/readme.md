# Nim

## Description
Ce projet implémente le jeu de Nim avec une intelligence artificielle utilisant l'apprentissage par renforcement (Q-learning). L'IA apprend à jouer de manière optimale en jouant plusieurs parties contre elle-même.

## Fonctionnalités
- Jeu de Nim avec des piles de jetons.
- IA utilisant un modèle Q-learning pour s'améliorer au fil des parties.
- Possibilité de jouer contre l'IA.

## Fichiers
- `nim.py` : Contient l'implémentation du jeu et de l'IA.

## Instructions
1. Assurez-vous d'avoir Python installé.
2. Pour entraîner l'IA, exécutez :
   ```bash
   python play.py
