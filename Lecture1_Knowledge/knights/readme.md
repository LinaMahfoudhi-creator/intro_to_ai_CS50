# Knights and Knaves

## Description
Ce projet implémente un moteur de logique pour résoudre des énigmes de type "Knights and Knaves". 
Les chevaliers (Knights) disent toujours la vérité, tandis que les menteurs (Knaves) mentent toujours. 
Le programme utilise des représentations logiques pour modéliser et résoudre ces énigmes.

## Fonctionnalités
- Représentation des énoncés logiques avec des classes comme `Symbol`, `And`, `Or`, `Not`, etc.
- Évaluation des modèles pour vérifier la validité des énoncés.
- Vérification des implications logiques entre les connaissances et les requêtes.

## Fichiers
- `logic.py` : Contient les classes et fonctions pour manipuler les énoncés logiques.
- `puzzles.py` : Définit des énigmes spécifiques et utilise le moteur logique pour les résoudre.

## Instructions
1. Assurez-vous d'avoir Python installé.
2. Exécutez le fichier `puzzle.py` pour résoudre les énigmes :
   ```bash
   python puzzles.py
