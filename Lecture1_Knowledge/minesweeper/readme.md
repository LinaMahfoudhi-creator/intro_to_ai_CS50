# Minesweeper AI

## Description
Ce projet implémente une intelligence artificielle capable de jouer au jeu du démineur. L'IA utilise des règles logiques pour déduire les cellules sûres et les mines, et effectue des mouvements aléatoires lorsque nécessaire.

## Fonctionnalités
- Représentation du plateau de jeu avec des mines placées aléatoirement.
- Déduction logique des cellules sûres et des mines.
- Génération de mouvements sûrs ou aléatoires.

## Fichiers
- `minesweeper.py` : Contient l'implémentation du jeu et de l'IA.

## Instructions
1. Assurez-vous d'avoir Python installé.
2. Exécutez le fichier `runner.py` pour jouer :
   ```bash
   python minesweeper.py
