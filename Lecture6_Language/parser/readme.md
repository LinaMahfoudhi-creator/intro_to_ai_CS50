# Parser

## Description
Ce projet implémente un analyseur syntaxique pour des phrases en anglais, basé sur une grammaire libre de contexte (CFG). 
Il identifie les structures syntaxiques et extrait les groupes nominaux (noun phrases) des phrases.

## Fonctionnalités
- Analyse syntaxique de phrases en anglais.
- Extraction des groupes nominaux (noun phrases).
- Prise en charge des phrases complexes avec des sous-phrases.

## Fichiers
- `parser.py` : Contient l'implémentation principale.
